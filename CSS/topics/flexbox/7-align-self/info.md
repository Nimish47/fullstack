## align-self

## used for individual flex items

## values:
   align-self: flex-start;
   align-self: center;
   align-self: flex-end;

   

## VIDEO
   similar to align-items but applied to flex-items individually
   not applied to flex-container
   align-items is applied to each flex-item and they have same value
   with align-self we can apply different align values to individual flex-item
