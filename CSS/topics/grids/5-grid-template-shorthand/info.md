## grid-template: shorthand
    rather than specifying grid columns and grid rows seperately, we can specify htem in one line, use grid-template.

## how to use:
    grid-template: row dimensions / column dimensions

## example:
    grid-template-columns: repeat(3,1fr);
    grid-template-rows: repeat(2,200px);

    above can be written shorthand as:
        grid-template: repeat(2,200px) / repeat(3,1fr);
