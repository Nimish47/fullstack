## position a div via:
    1. position property
    2. grid-areas


## Answer:
    Position property PROS AND CONS
        very good when fixed values are used for container and child elements
        not meant to be used with fraction units (subject to more research)        


    Grid property PROS AND CONS
        good if grid-column/rows, grid-element values all are in fraction units
        not good if fixed values are used (pixels), breaks at certain points.
