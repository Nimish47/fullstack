## justify content

position grid content on main axis

## values:
    justify-content: start; (default)
    justify-content: space-around;
    justify-content: center;
    justify-content: end;
    justify-content: space-evenly;
    and many more...


## understanding -> justify-content: space-evenly;    
    collction of grid elements column wise distrubutes itself w.r.t grid line and on main axis
    here it distributes itself evenly w.r.t grid line


## for below values, justify-content works container-wise
            justify-content: start; (default)
            justify-content: center;
            justify-content: end;

## for below values, justify-content works column-wise 
                justify-content: space-around;  
                justify-content: space-evenly;          
                and more..

## justify-content never works grid-element wise
